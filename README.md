# 🎯 Quiz Game

A simple and interactive **Quiz Game built using Python**.
The game allows users to answer multiple-choice questions and calculates their final score.

## ✨ Features

* Multiple-choice questions
* User-friendly console interface
* Automatic answer checking
* Score calculation
* Simple and beginner-friendly Python code

## 🛠️ Technologies Used

* Python 3
* Variables
* Conditional Statements
* Loops
* User Input

## 🚀 How to Run

1. Make sure **Python 3** is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python editor.
4. Run the Python file:

```bash
python quiz_game.py
```

## 🎮 How to Play

1. Start the program.
2. Read each question.
3. Enter your answer.
4. The program checks your answer.
5. Your final score is displayed at the end.
